Installation

moments requires Python 3.11 or newer (up to 3.15).

Using pip

The simplest way to install the latest stable version of moments is to

pip install moments-popgen

This installs moments along with the minimal dependencies, and you should be able to import moments.

Warning

Our package on PyPI is named moments-popgen. Running pip install moments installs a different, unrelated package that is also imported as moments. If you installed it by mistake, run pip uninstall moments and then reinstall ours with pip install --force-reinstall moments-popgen, since the two packages write to the same moments directory.

To install the development version of moments, you can install directly from the development branch at Github:

pip install git+https://github.com/MomentsLD/moments.git@devel

Alternatively, you can clone the git repository and install from source (use pip install -e . for an editable, development install):

git clone https://github.com/MomentsLD/moments.git
cd moments
pip install .

Using conda

moments is available via Bioconda, and can be installed by running

conda install -c conda-forge -c bioconda moments

Alternatively, you can set up your conda channels to include bioconda and conda-forge, as recommended by Bioconda, by running

conda config --add channels bioconda
conda config --add channels conda-forge
conda config --set channel_priority strict

after which conda install moments will install moments from Bioconda.

Dependencies and details

Installing with pip installs the required dependencies automatically:

  • numpy (>= 2.0, < 3.0)

  • scipy (>= 1.13)

  • cython (>= 3.1)

  • mpmath (>= 1.0, < 1.4)

  • demes (>= 0.2)

Some features need additional packages:

  • Plotting: matplotlib

  • Parsing VCFs with moments.LD.Parsing, which computes LD statistics to compare to predictions from moments.LD: scikit-allel, h5py, and pandas

We also strongly recommend installing ipython for interactive analyses.

For development, requirements.txt lists the dependencies. From the moments directory, these can be installed with

python -m pip install -r requirements.txt

or, using conda,

conda install -c conda-forge --file requirements.txt

To build the documentation locally, install moments along with the packages in requirements/docs.txt, and then run make html in the docs directory:

python -m pip install . -r requirements/docs.txt
cd docs
make html

The pages are written to docs/_build/html.

You should then be able to import moments in your python scripts. Entering an ipython or python session, type import moments. If, for any reason, you have trouble installing moments after following these steps, please submit an Issue.
