Two-locus frequency spectrum

See Selection at two loci for introduction and examples to the Two-Locus extension.

Parameters and selection models

moments.TwoLocus models a single population. Times are measured in units of \(2N_e\) generations and sizes are relative to the ancestral \(N_e\). The recombination rate between the two loci is rho \(= 4N_e r\), and the mutation rate at each locus under the default infinite sites model is theta \(= 4N_e u\).

Selection is specified in one of three ways, and at most one may be given:

  • gamma: additive selection with the same coefficient \(\gamma = 2N_e s\) at both loci and no epistasis. This is shorthand for sel_params = [2 * gamma, gamma, gamma], so that the single-locus spectrum at each locus matches the single-site SFS with selection coefficient \(\gamma\) and \(h = 1/2\). (With the reversible mutation model, finite_genome=True, gamma is instead additive selection at the left locus only.)

  • sel_params = [gamma_AB, gamma_A, gamma_B]: additive selection within loci, with scaled selection coefficients for the AB, Ab, and aB haplotypes relative to ab. For example, selection at only the left locus is [gamma, gamma, 0], and there is epistasis if gamma_AB != gamma_A + gamma_B.

  • sel_params_general: scaled selection coefficients for each of the nine diploid two-locus genotypes relative to ab/ab, which allows for dominance.

The helper functions in moments.TwoLocus.Util (below) construct sel_params and sel_params_general for common selection models.

API

The TLSpectrum class handles all manipulations of the two-locus frequency spectrum:

class moments.TwoLocus.TLSpectrum(data, mask=np.False_, mask_infeasible=True, mask_fixed=False, data_folded=None, check_folding=True, dtype=<class 'float'>, copy=True, fill_value=nan, keep_mask=True, shrink=True)[source]

Represents a two-locus frequency spectrum.

The left locus carries alleles A/a and the right locus B/b, where A and B are the derived alleles. In a sample of n haploid copies, entry F[i, j, k] is the number (or density) of pairs of loci with i copies of the AB haplotype, j copies of Ab, and k copies of aB (the remaining n - i - j - k copies are ab). The derived allele counts are thus i + j at the left locus and i + k at the right locus.

Parameters:

  • data (array) – The frequency spectrum data, which has shape (n+1)-by-(n+1)-by-(n+1) where n is the sample size.

  • mask (array) – An optional array of the same size as data. ‘True’ entries in this array are masked in the TLSpectrum.

  • mask_infeasible (bool) – If True, mask all bins for frequencies that cannot occur, i.e. i + j + k > n. Defaults to True.

  • mask_fixed (bool) – If True, mask the bins in which either locus is not segregating (see mask_fixed()). Defaults to False.

  • data_folded (bool) – If True, it is assumed that the input data is folded by the minor allele at each locus.

  • check_folding (bool) – Not currently used.

D(proj=True, nA=None, nB=None)[source]

Return the expectation of \(D\) from the spectrum.

This is the sum over unmasked entries in which both loci are segregating, weighting each entry by its estimate of the statistic. It is not normalized by the total of the spectrum, so ratios such as F.D2() / F.pi2() (the \(\sigma_d^2\) statistic) are typically reported.

Parameters:

  • proj – If True, use the unbiased estimator from downsampling. If False, use naive maximum likelihood estimates for frequency.

  • nA – If given, only include entries with derived allele count nA at the left locus. If None, include all counts.

  • nB – If given, only include entries with derived allele count nB at the right locus. If None, include all counts.

integrate(nu, tf, dt=0.01, rho=None, gamma=None, sel_params=None, sel_params_general=None, theta=1.0, finite_genome=False, u=None, v=None, alternate_fg=None, clustered_mutations=False)[source]

Integrate the two-locus frequency spectrum forward in time, modifying the spectrum in place. This integration scheme takes advantage of scipy’s sparse methods.

Selection is specified in one of three ways (at most one may be given):

  • gamma: additive selection with the same coefficient at both loci and no epistasis. Under the infinite sites model, this is shorthand for sel_params = [2 * gamma, gamma, gamma]. With finite_genome=True, gamma is instead additive selection at the left locus only, which is the only selection model available for the reversible mutation model.

  • sel_params = [gamma_AB, gamma_A, gamma_B]: additive selection within loci for the AB, Ab, and aB haplotypes relative to ab. This allows for different selection coefficients at the two loci, and for epistasis if gamma_AB != gamma_A + gamma_B.

  • sel_params_general: selection coefficients for each of the nine diploid two-locus genotypes, which allows for dominance.

Parameters:

  • nu – Population size relative to the ancestral (reference) size, given as a positive number or as a function of time.

  • tf (float) – The integration time, in units of 2*Ne generations.

  • dt (float) – The time step for integration.

  • rho (float) – The population-size scaled recombination rate, 4*Ne*r. If not given, rho = 0 is used and a warning is printed.

  • gamma (float) – The population-size scaled selection coefficient, 2*Ne*s. See above for how it is applied.

  • sel_params (list) – Additive selection parameters [gamma_AB, gamma_A, gamma_B], each given as 2*Ne*s for that haplotype relative to ab. Only used with the infinite sites model. See moments.TwoLocus.Util.additive_epistasis().

  • sel_params_general (list) – Selection parameters for the nine diploid genotypes relative to ab/ab, each given as 2*Ne*s for that genotype, in the order [AB/AB, AB/Ab, AB/aB, AB/ab, Ab/Ab, Ab/aB, Ab/ab, aB/aB, aB/ab]. Only used with the infinite sites model, and requires a sample size of at least 13. See moments.TwoLocus.Util.simple_dominance() and moments.TwoLocus.Util.gene_based_dominance().

  • theta (float) – The population-size scaled mutation rate at each locus, 4*Ne*u, under the infinite sites model.

  • finite_genome (bool) – Defaults to False, in which case we use the infinite sites model. Otherwise, we use a reversible mutation model, and must specify u and v.

  • u (float) – The mutation rate at the left locus in the finite genome model, given as 2*Ne*mu (that is, half of theta_fd in the single-site reversible model). Forward and backward mutation rates are equal.

  • v (float) – The mutation rate at the right locus in the finite genome model, with the same scaling as u.

  • alternate_fg (bool) – If True, use the alternative finite genome model. This parameter will be deprecated when we clean up the numerics and integration.

  • clustered_mutations (bool) – If True, new mutations under the infinite sites model arise as AB haplotypes at both loci at once, instead of arising on the background of the other locus.

The Demographics module contains some standard demographic models. This is a good place to look for some inspiration to create your own two-locus models as well.

Equilibrium spectra and simple single-population demographic models for the two-locus frequency spectrum: two-epoch, three-epoch, exponential growth, and bottleneck followed by exponential growth.

All models use the infinite sites mutation model. Selection may be specified with gamma (additive selection with the same coefficient at both loci and no epistasis) or with sel_params (additive selection within loci, allowing for different coefficients at the two loci and epistasis). equilibrium() also accepts sel_params_general, which allows for dominance.

moments.TwoLocus.Demographics.bottlegrowth(params, ns, rho=None, theta=1.0, gamma=None, sel_params=None)[source]

A bottleneck followed by exponential growth. The population changes size to nuB at time T ago, and then has exponential size change to final size nuF. Time is in units of 2Ne generations, and sizes are relative to the ancestral Ne.

Parameters:

  • params – Given as [nuB, nuF, T].

  • ns – The haploid sample size.

  • rho – The population-size scaled recombination rate between the two loci, 4*Ne*r. If not given, rho = 0 is used and a warning is printed.

  • theta – The population-size scaled mutation rate at each locus, 4*Ne*u. Defaults to 1.

  • gamma – The population-size scaled selection coefficient, 2*Ne*s, for additive selection with the same coefficient at both loci and no epistasis. This is shorthand for sel_params = [2 * gamma, gamma, gamma], so that the single-locus spectrum at each locus matches the single-site SFS with selection coefficient gamma and h = 1/2. For selection at only one locus, unequal selection, or epistasis, use sel_params instead. Cannot be combined with sel_params.

  • sel_params – Additive (within-locus) selection parameters for the AB, Ab, and aB haplotypes relative to ab, given as [gamma_AB, gamma_A, gamma_B], where each is 2*Ne*s for that haplotype. For example, selection only at the left locus is [gamma, gamma, 0]. With gamma_AB = gamma_A + gamma_B there is no epistasis. See moments.TwoLocus.Util.additive_epistasis().

Returns:

The two-locus frequency spectrum, as a moments.TwoLocus.TLSpectrum.

moments.TwoLocus.Util.additive_epistasis(s, epsilon=0, Ne=None)[source]

Returns the additive selection parameters [gamma_AB, gamma_A, gamma_B], to be passed as sel_params, for a model with the same selection coefficient at both loci and multiplicative epistasis: [2 * gamma * (1 + epsilon), gamma, gamma].

In this model, epsilon of 0 is no epistasis, epsilon > 0 is synergistic epistasis, while epsilon < 0 is antagonistic epistasis. Note that epsilon < -1 will flip the sign of the selection coefficient for AB.

Parameters:

  • s (float) – The selection coefficient at each locus. If Ne is None, this is the population-size scaled coefficient gamma = 2*Ne*s. If Ne is given, this is the unscaled coefficient s, and gamma = 2*Ne*s is computed.

  • epsilon (float) – The epistasis parameter.

  • Ne (float) – The effective population size, used to scale s. Optional.

moments.TwoLocus.Util.gene_based_dominance(s, h=0.5, Ne=None)[source]

Returns the general selection parameters, to be passed as sel_params_general, for the gene-based dominance model, in which fitness depends on how many of an individual’s two haplotypes carry at least one derived allele. The parameters are given for diploid genotypes in the order [AB/AB, AB/Ab, AB/aB, AB/ab, Ab/Ab, Ab/aB, Ab/ab, aB/aB, aB/ab]: genotypes with one such haplotype (AB/ab, Ab/ab, aB/ab) have selection coefficient 2*h*gamma, and genotypes with two such haplotypes have 2*gamma.

  • Ne (float) – The effective population size, used to scale s. Optional.

moments.TwoLocus.Util.simple_dominance(s, h=0.5, Ne=None)[source]

Returns the general selection parameters, to be passed as sel_params_general, for the simple dominance model with a single selection and dominance coefficient that applies to both loci. The parameters are given for diploid genotypes in the order [AB/AB, AB/Ab, AB/aB, AB/ab, Ab/Ab, Ab/aB, Ab/ab, aB/aB, aB/ab], where a genotype with one copy of a derived allele has selection coefficient 2*h*gamma and one with two copies has 2*gamma, summed over the two loci.

Fitness effects add across loci (no epistasis), which matches multiplicative fitness when selection is weak enough that the product of the selection coefficients at the two loci can be ignored. With h = 1/2, this is equivalent to sel_params = [2 * gamma, gamma, gamma].

Parameters:

  • s (float) – The selection coefficient. If Ne is None, this is the population-size scaled coefficient gamma = 2*Ne*s. If Ne is given, this is the unscaled coefficient s, and gamma = 2*Ne*s is computed.

  • h (float) – The dominance coefficient.

  • Ne (float) – The effective population size, used to scale s. Optional.

moments.TwoLocus.Inference.optimize_log_fmin(p0, data_list, model_func, rhos=[0], lower_bound=None, upper_bound=None, verbose=0, flush_delay=0.5, epsilon=0.001, pgtol=1e-05, multinom=True, maxiter=100000.0, full_output=False, func_args=[], func_kwargs={}, fixed_params=None, output_file=None)[source]

Optimize log(params) to fit a model to two-locus data binned by recombination distance, using the downhill simplex algorithm (scipy.optimize.fmin).

The model spectrum for each bin is computed by integrating over rho within the bin using Simpson’s rule, from the model evaluated at the bin edges and midpoints.

Parameters:

  • p0 – Initial parameters.

  • data_list – List of two-locus frequency spectra, one for each rho bin.

  • model_func – Function that takes (params, ns, rhos=rhos) and returns a list of model spectra, one for each value in rhos.

  • rhos – The edges of the rho bins, so len(rhos) == len(data_list) + 1.

  • lower_bound – Lower bounds on parameter values. Use None for no bound.

  • upper_bound – Upper bounds on parameter values. Use None for no bound.

  • verbose (int) – If greater than zero, print optimization status every verbose steps.

  • flush_delay (float) – Standard output will be flushed once every flush_delay minutes.

  • epsilon – Not used.

  • pgtol – Not used.

  • multinom (bool) – If True, the model is optimally rescaled to the data within each bin (multinomial likelihood). If False, the Poisson likelihood is used.

  • maxiter (int) – Maximum number of iterations.

  • full_output (bool) – If True, return the full output of scipy.optimize.fmin, (xopt, fopt, iter, funcalls, warnflag). Otherwise, return only the best-fit parameters.

  • func_args – Not used.

  • func_kwargs (dict) – Additional keyword arguments to model_func.

  • fixed_params – If not None, a list of the same length as p0, in which non-None values are held fixed during optimization.

  • output_file (str) – If given, write optimization status to this file instead of standard output.
